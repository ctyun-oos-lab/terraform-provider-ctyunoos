# Security

## Reporting a Vulnerability

The maintainers take security issues seriously. To report a vulnerability,
please use the **private vulnerability reporting** feature on the repository's
Security tab (GitHub Security Advisories) rather than opening a public issue.

Include:

- The affected provider version(s).
- The affected resource or data source, if applicable.
- A description of the vulnerability and, where possible, steps to reproduce it.

The maintainers will acknowledge the report and provide an update on its
resolution. Please do not disclose the details publicly until a fix is available.

## Supported Versions

Security fixes are provided for the latest release (currently `1.0.x`) and are
released in the next patch or minor release.
